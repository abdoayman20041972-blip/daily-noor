# نور اليوم — تطبيق Expo بسيط

3 شاشات فقط: آية اليوم، حديث اليوم، ذكر اليوم. بيتغيروا تلقائيًا كل يوم (منتصف الليل بتوقيت الجهاز).
بيشتغل بدون إنترنت. الدارك/اللايت بيتبعوا إعداد الهاتف.

## الملفات
- `App.js` الشاشات الثلاث وشريط التنقل
- `src/data.js` المحتوى (20 آية / 20 حديث / 20 ذكر) — زوّد فيه براحتك
- `src/theme.js` ألوان اللايت والدارك
- `assets/icon.png` و `assets/adaptive-icon.png` الأيقونة
- `eas.json` بروفايل `preview` بيطلّع APK

## الرفع والبناء
1. ارفع محتويات هذا المجلد على ريبو GitHub (جذر الريبو = هذا المجلد).
2. في expo.dev: أنشئ/اختر مشروع واربطه بالريبو.
3. Build → Android → profile: `preview` → هيطلع لك لينك APK.
